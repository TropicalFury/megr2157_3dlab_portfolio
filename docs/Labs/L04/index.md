# L04 – Benchmark a Parameter

## Prompt
This assignment was centered on the testing of a parameter of the Prusa Core One FDM printer, the machines we use in the Rapid Printing Lab. I had to design a part that would serve as the test object for one of the four proven benchmark tests:
- Overhang angle test
- Pull strength test
- Tolerance gauge test
- Dimension calibration test

**Test Choice** 

After some initial thought I decided to commit my part to a dimension calibration test of the Prusa Core One. I specifically wanted to see how accurate the machine could get to the measurements I set in the CAD modeling process and what tolerances would have to accounted for given the range of error in the test. I also wanted my part to be easily replicable to make the testing of dimensions across the machines a fast and seamless process.

**Prediction**

I predicted that the test would give resultant tolerances of +/- .005 thousands of an inch for the dimensions stated, a relatively safe and even guess for I had not had much experience with the precision of 3D printing up to this point. I had set to making the measurement increments change by one tenth of an inch so having tolerances in thou would give me clear percentages for how close the prints would be.



With all the setup out of the way, I moved onto the part's design phase.
## Design
I wanted something small as to not use up a lot of material and something that would test how consistent the printing accuracy is for increasingly smaller measurements across the different machines to show if any settings needed to be rained in. I had seen many previous designs measure how protrusions off a base plate were different depending on slight changes in set dimension and others that had only one dimension to measure in one direction, requiring only two points of measurements. I chose to combine aspects of both of these to make my part. This would result in a base plate that had protrusions that stood as points of measurement, but the intention was to measure the space in between the protrusions.
